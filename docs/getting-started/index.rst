Getting Started
===============

Use this section to understand what ``sfdctrust`` covers and to set up a
development checkout.

1. Read :doc:`overview` for the project scope, status and requirements.
2. Follow :doc:`installation` to install the package from source.

A quickstart will be added once the client and its resource operations are
available. Until then, see :doc:`../reference/index` for the verified API
contract that the implementation will follow.
